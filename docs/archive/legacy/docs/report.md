## 工作距离校核

使用逐 cell 的局部投影最小奇异值，并对法线倾斜方位按 5° 扫描。下列距离是相机到图案中心，法线夹角为45°，板中心在光轴；相机偏离中心时应重新计算，不把这个值当作任意取景的保证。
