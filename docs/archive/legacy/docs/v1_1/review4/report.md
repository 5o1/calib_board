3. 没有定位投影误差的唯一原因。低重投影误差与较高工作区投影误差同时存在，是本次已测事实；不能直接推定内置精化、渲染采样或打印是主因。如后续需区分候选原因，可在固定失败姿态下比较检测角点与其已知真值投影的偏差方向，再用独立采样模型作对照；此因果诊断本轮未执行，也未据此修改任何生成/检测参数。
